ExchangeRate.dev provides a RESTful JSON API delivering current and historical foreign exchange rates for developers. It covers over 10,000 currency pairs across 144 currencies, offering live market data with source timestamps and optional historical look‑back. The free tier grants 5,000 requests per month without requiring a credit card, while paid plans unlock higher limits and premium features. Documentation includes quickstart guides, API reference, pricing, status, and legal pages.
